# D — Doomscrolled Till Sunrise

Entry for the make.fun competition
`u-puan-one-letter-for-your-day-e54e9c36` — a program that writes exactly one
letter to `/output/entry.txt`.

Bounty page: https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36

## The letter

> D

## The word behind it

**D is for "doomscrolled till sunrise."** One thumb, one feed, one more
video — and suddenly the sky outside the window is light again. Vivid (you
can see the pale dawn through the blinds), funny (the scroll won, the sleep
lost, 4–0), and true (everyone has lived this day at least once).

## How it runs

`main.ts` (Node 22, stdlib only) writes the single letter `D` to
`/output/entry.txt` — 1 byte, no network, fully deterministic: two runs
produce byte-identical output.
